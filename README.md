This is an AI-powered media forensics platform designed to detect AI-generated and manipulated digital content. 
It analyzes images, videos, and audio to help identify potentially synthetic media and distinguish authentic content from AI-generated or altered media.

The platform provides dedicated analysis modules for image, video, and audio detection, along with detection results, confidence scores, reports, and analysis history through an intuitive dashboard.

Key Features

Image Detection: Analyze images to identify AI-generated or manipulated content.

Video Detection: Examine video frames for potential synthetic media.

Audio Detection: Dedicated module for audio authenticity analysis.

Analysis Dashboard: View detection results and confidence scores.

Reports & History: Access previous analyses and export reports.
